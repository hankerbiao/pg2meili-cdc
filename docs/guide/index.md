# 开发指南概览

UniData 提供“单写多搜”的数据同步与搜索能力。这里汇总了你需要了解的核心概念与阅读路径。

![系统架构图](/images/主要架构图.png)

## 1.1 设计思路

- **写入集中**：业务只写主库，避免双写逻辑。
- **同步自动化**：通过 CDC 捕获变更，推送到搜索侧。
- **就近检索**：查询流量落到最近的搜索节点。

## 1.2 核心价值

- **解耦**：写入与搜索独立扩展，互不阻塞。
- **可观测**：数据库 → Kafka → 搜索引擎链路清晰。
- **可伸缩**：多地部署与扩容更易管理。

## 1.3 方案对比

| 维度 | 直接对接搜索引擎 | UniData + CDC 架构 |
| :--- | :--- | :--- |
| 一致性 | 依赖双写，风险较高 | 变更捕获，最终一致 |
| 侵入性 | 需要集成 SDK | 业务侧改动少 |
| 多地同步 | 需自研 | 架构内建 |
| 运维成本 | 低 | 中高 |
